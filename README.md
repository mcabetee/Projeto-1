# Sala de Tarefas
## Site de Organização de Estudos

Bem-vindo ao Projeto 1, Inicialmente, o objetivo é criar uma ferramenta simples que facilite a organização da rotina escolar. O sistema tem como objetivo ajudar estudantes a organizar suas tarefas e atividades escolares em um único site. A proposta é permitir o cadastro das disciplinas, o registro de tarefas, prazos de entrega e o acompanhamento das atividades pendentes e concluídas. 

## 💻 Tecnologias utilizadas
- HTML5 – Estrutura do site
- CSS3 – Estilização e design
- JavaScript – Interatividade
- Git e GitHub – Controle de versão e hospedagem do projeto

## Fases do Desenvolvimento
As fases de requisitos, análise, projeto, implementação, testes e manutenção acontecerão em ciclos. Em cada versão, os requisitos serão analisados, o projeto será planejado, as funcionalidades serão implementadas e testadas.

## Este projeto foi criado para praticar e desenvolver habilidades em:

- Estruturação de páginas com HTML;
- Estilização avançada com CSS;
- Interatividade com JavaScript;
- Organização e documentação de projetos no GitHub
